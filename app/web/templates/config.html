打印机（局域网模式，支持多台）

在打印机屏幕：设置 → 网络，可以看到 IP、访问码（Access Code），序列号（SN）在设置 → 设备信息里。拓竹 X1 / P1 / A1 / H2 系列都适用。 新版固件如果连不上，可能需要打开"仅局域网模式"（部分机型还需要开发者模式）。

推送类别

只有勾选的类别才会向下面的渠道推送；仪表盘的报警记录不受影响，所有事件都会记录。

自定义错误代码

收到错误代码时，推送和报警记录里会显示你填的说明；没填的会显示代码本身（含十六进制），方便查询后补充。代码支持十进制或 0x 开头的十六进制，# 开头的行会被忽略。

Telegram

没有 Bot：找 @BotFather 发 /newbot 创建拿到 Token；给新 Bot 发一条消息后访问 https://api.telegram.org/bot<TOKEN>/getUpdates 可以看到 chat id。

自定义 Webhook（可添加多个：飞书 / 企业微信 / 钉钉机器人、n8n 等）

每个 Webhook 都会收到所有勾选类别的推送，可以单独停用。Body 模板里用 {title} / {message} 做占位符。
飞书：{"msg_type":"text","content":{"text":"{message}"}}
企业微信 / 钉钉：{"msgtype":"text","text":{"content":"{message}"}}（钉钉需要在消息里带上机器人设置的关键词）
"发送测试推送"使用的是已保存的配置，改完请先点保存。

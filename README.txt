拓竹打印机报警器 (Bambu Lab Print Alarm)
========================================

通过打印机的"局域网模式"实时监听状态，在暂停（含 AI 检测到炒面）、出错、失败、
完成时，推送到 Telegram / Bark / ntfy / 自定义 Webhook（飞书、企业微信、钉钉机器人等）。
支持多台打印机，带网页管理界面，所有设置都在网页里填，不用改配置文件。

适用机型：拓竹 X1 / P1 / A1 / H2 系列 FDM 打印机（协议相同）。
已在 H2D 上实际使用；其他机型按相同协议编写，未逐一实测。


一、部署（Docker）
------------------
1. 把整个文件夹放到服务器 / NAS 上（群晖：Container Manager -> 项目 -> 新增，指向该文件夹）。
2. 编辑 docker-compose.yml，设置网页密码：WEB_PASSWORD（强烈建议）。
3. 构建并启动：
       docker-compose up -d --build
   群晖网页界面：项目 -> 构建 -> 启动。
4. 浏览器打开 http://<服务器IP>:8000 ，点右上角"配置"。


二、配置
--------
1. 打印机：在打印机屏幕 设置 -> 网络 里找到 IP 和访问码（Access Code），序列号在
   设置 -> 设备信息。可添加多台。新版固件如连不上，需开启"仅局域网模式"
   （部分机型还要开发者模式）。
2. 推送类别：勾选哪些事件需要推送（暂停 / 异常 / 失败 / 完成 / 开始）。
   所有事件都会记录在仪表盘，不受勾选影响。
3. 推送渠道：至少配置一个，保存后点"发送测试推送"验证。自定义 Webhook 可以添加任意多个
   （比如同时推到飞书群和 n8n），每个可单独停用，测试结果会逐个显示。
4. 错误代码含义：默认自动使用拓竹官方的错误代码说明（按序列号前三位识别机型，联网获取后缓存到
   data/hms_*.json，每天更新一次，断网时用缓存）。网页里可选中文 / English。
   想覆盖某个代码的说明，在"自定义覆盖"里写 "代码=说明"，例如 83918991=摄像头清理暂停
   （自定义优先，没写的用官方）。官方库里没有的新代码只会显示代码本身。
   测试：浏览器打开 http://<服务器IP>:8000/api/error-code/50364419 看能否查到说明。


三、小智 AI（可选）
-------------------
在 xiaozhi.me 智能体控制台的 MCP 接入点里复制 wss:// 开头的地址，填到
docker-compose.yml 的 MCP_ENDPOINT，然后重建 mcp 容器。之后可以直接问小智
"打印机现在怎么样"。注意这是一问一答，小智不会在打印机出事时主动开口。


四、升级与数据
--------------
- 配置和状态保存在 ./data（config.json / state.json），覆盖程序文件、重建镜像都不会丢。
- 代码目录是挂载进容器的：只改 app/ 下文件，重启容器即可；改了 requirements.txt
  或 Dockerfile 才需要重新构建。
- 访问码、Token 以明文存在 data/config.json，请注意保护这个文件，不要公开分享。


五、说明
--------
- 首次连上某台打印机时，只记录当前状态，不会推送；之后的状态变化才会推送，
  所以重启程序不会重复推送"打印完成"。
- 网页没有 HTTPS，不要直接暴露到公网；需要远程访问请走 VPN / 内网穿透并设置密码。
- mcp_pipe.py 改自小智官方示例 https://github.com/78/mcp-calculator （MIT 协议）。
